## Exercises

1. [Data Flow Walkthrough](../../../ml/docs/bootcamp/01-data-flow-walkthrough.md) — trace a case from Cloud SQL → BigQuery ETL → feature materialization → dataset export → GCS
2. [Train a Model Locally](../../../ml/docs/bootcamp/02-train-locally.md) — run the XGBoost training container on a sample dataset
3. [Submit a Pipeline](../../../ml/docs/bootcamp/03-submit-pipeline.md) — compile and submit a KFP pipeline to Vertex AI on dev
4. [Evaluate and Promote](../../../ml/docs/bootcamp/04-evaluate-and-promote.md) — run the eval harness, interpret metrics, promote a model
5. [Deploy to Serving](../../../ml/docs/bootcamp/05-deploy-to-serving.md) — deploy a model, send a test prediction, verify BQ logging
6. [Monitor and Retrain](../../../ml/docs/bootcamp/06-monitor-and-retrain.md) — trigger drift computation, read dashboard, invoke retraining
7. [Add a New Capability](../../../ml/docs/bootcamp/07-add-new-capability.md) — guided exercise to add a toy third capability
8. [Graph Features Pipeline](../../../ml/docs/bootcamp/08-graph-features.md) — run the Dataflow pipeline locally, inspect output features
9. [Looker Studio Dashboard](../../../ml/docs/bootcamp/09-looker-dashboard.md) — connect BigQuery to Looker Studio, build dashboard
