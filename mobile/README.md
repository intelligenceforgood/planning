# Mobile Workstream

This folder contains product and technical plans for the i4g mobile apps (iOS and Android). The mobile experience is a **subset** of the web `ui/` Next.js console and follows the platform architecture documented in `proto/docs/architecture.md` and `proto/docs/tdd.md`.

Documents:
- `prd.md` — Product requirements for the first mobile release.
- `tdd.md` — Technical design for mobile clients and service integration.
- `roadmap.md` — Phased delivery plan and staffing.
- `repo_structure.md` — Proposed repository layout to mirror existing mono-repo conventions.
- `open_questions.md` — Items requiring product/security decisions.
- `design_tokens.md` — Token plan plus the current Style Dictionary scaffold in `mobile/shared/design-tokens/`.
- `tokens.json` — Stub token file (overwritten once the export script targets `ui/` tokens).
- `poc_ios_bff.md` — Local BFF PoC guide using the Next.js app and iOS simulator.
