## PRD §10 open question answers (verified 2026-04-21)

1. **Decision free-text comment?** ✅ **Resolved — not a blocker.** The endpoint accepts `notes: string | null` (optional). Field is `notes`, not `comment`. J6 is unblocked.
2. **Reports: signed URL or proxied stream?** ⚠️ **Partially resolved.** `/reports/{report_id}/download` endpoint exists but local library is empty — can't inspect redirect headers. Not a blocker for Sprint 1; revisit in Sprint 3 (J5).
3. **Dashboard counts endpoint?** ✅ **Resolved.** `GET /dashboard/overview` exists and returns `metrics[]` + `activity[]` cheaply. No pagination. `DashboardCounts` shape replaced by `DashboardOverview`.
4. **IAP Google domain whitelist?** ❌ **Cannot verify locally** — IAP is disabled in `local` profile. Document in `developer-guide.md` before Sprint 4 (google-pkce-iap wiring).
